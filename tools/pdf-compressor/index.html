How it works

  1. Add your PDFDrop the file in — you’ll see its size, page count and a preview.
  2. Pick a methodImage compression gives the largest savings for scans and image-heavy files. Lossless keeps text selectable.
  3. Compare and downloadSee the exact before/after size. If compression wouldn’t help, the tool tells you instead of handing back a bigger file.

Questions

Is my PDF uploaded to a server?

No. The PDF is read and compressed inside your browser tab. Nothing is sent anywhere.

Which method should I choose?

For scanned documents, photos and brochures, use Image compression (Balanced). For text-heavy reports and contracts where copy-paste matters, try Lossless first.

Why is text not selectable after compressing?

Image compression re-draws each page as an optimised image. Use Lossless if you need searchable text.

Why did my file barely shrink?

Some PDFs are already optimised. The tool never gives you a larger file — it will recommend keeping the original.
