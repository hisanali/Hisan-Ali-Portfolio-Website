    How it works

    1. Add your PDFsDrop them onto the page or browse. Each file shows its page count and a preview of page one.
    2. Arrange and trimDrag to reorder, rotate sideways scans, and type page ranges like 1-3, 7 to include only what you need.
    3. Merge and downloadThe merged PDF is built in your browser and downloads immediately.

    Questions

    Are my files uploaded anywhere?

    No. Merging happens entirely inside your browser using JavaScript — the files never leave your device.

    Is there a file size or count limit?

    There is no fixed limit. Very large documents (hundreds of MB) depend on your device memory.

    Why is a file marked as password-protected?

    Encrypted PDFs can’t be merged until the password is removed. Open it in a PDF reader, save an unlocked copy, and add that instead.

    Will links and text stay selectable?

    Yes. Pages are copied as-is, so text, vector graphics and most links are preserved.
